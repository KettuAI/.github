## Beauty is productivity.

Kettu puts Claude Code, Codex, OpenCode, Pi and 40+ more coding agents side by side in one window that looks good and feels right. It runs on macOS, Windows and Linux, and you can carry on from an iPhone or any browser.

- **All your agents in one place**: your own installs, accounts and settings. Run sessions in parallel, and the sidebar shows which one is working, which one waits for you and which one is done.
- **You stay in control**: see what an agent wants to run or change, then allow or deny it with one key. Answer its questions and approve its plans in cards.
- **A workbench beside every session**: diffs, files, a terminal, Git, worktrees, a built-in browser and the pages agents make.
- **From anywhere**: reach your computers from the iPhone app or [app.kettu.sh](https://app.kettu.sh), end-to-end encrypted.
- **Yours**: open source under AGPL-3.0. Your sessions, code and files stay on your own computers.
